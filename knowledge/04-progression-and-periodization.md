# Progression & Periodization

*Source: transcripts 1, 2, 3, 6, 9, 10, 12, 13, 15, 16, 18*

## Core Principle

**Progressive overload is king** — "it's the progression from week to week that drives progress, not monumental effort in any one workout" [T16]. Every effective program is a vehicle for forcing measurable progress in the logbook [T2].

Overload routes beyond adding weight [T1, T3]:
- Add reps at the same weight
- Add a set
- Improve technique (tighter eccentric, less momentum, better ROM, deeper stretch)
- Improve mind-muscle connection
- Swap to a more effective exercise

## Week-to-Week Progression Methods [T6]

**Block structure:** 3–6 overload weeks then 1 deload (advanced ≈ 3 weeks, novices longer; typical: 4 overload + 1 deload).

1. **Add reps weekly** (Method A): work at 1–3 RIR, log every set (expect drop-off across sets, e.g., 9/8/7/6). Add 1–3 reps per set per week (fewer for advanced).
2. **Add sets weekly** (Method B): e.g., chest 14 → 15 → 16 → 17 sets across the block, then deload.
3. **Increase RPE weekly** (Method C): RPE 6 → 7 → 8 → 9 across 4 weeks; reps naturally rise as proximity to failure increases.

**Double progression** (classic, used throughout history): find your rep-range weight (e.g., 8RM), rep up to the top of the range (12), then add weight and restart at 8 [T1, T2 — Hackenschmidt, Reeves].

## Block-to-Block Periodization [T6]

- Something must change after every block — even tiny (1–2 more reps/week, +2% load)
- Can't progress linearly forever → cycle load/rep range:
  - Bench 12–15 reps block → next block **+5–10% load, lower rep range** → progress reps 3–5 weeks → deload → repeat
  - When reps drop below ~6 in that cycle → **swap the exercise** (same muscle) after 2–5 load-increase blocks
- "If you do the optimal thing year-round it's no longer optimal" — volume is a dial to turn up/down by phase [T2]
- Alternate high-volume blocks with lower-volume, logbook-focused blocks [T2]

## 3-Week Waves (volume cycling) [T12]

For intermediate/advanced or 35+ lifters who stall on linear progression:
- Week 1: 5×5 @ 75% 1RM → Week 2: 5×4 @ 80% → Week 3: 5×3 @ 85%
- Continuation options for weeks 4–6:
  1. Add weight, keep sets/reps
  2. Keep weight, add reps
  3. Speed/density: convert to doubles (12×2 @50%-ish, max bar velocity) or cut rest from 5–8 min → 2–3 min — "makes you really strong in a hurry," requires conditioning

## Conjugate Progression [T9, T10, T11]

- Rotate main max-effort lifts **weekly**; accessories every **3–4 weeks** or when progress stalls
- Expect PR progress at least every 8 weeks (5–10% on max effort exercises)
- Beginners: don't rotate too frequently

## Novice Linear Progression [T13, T16]

- Novice LP lasts 3–6 months (add 5–10 lb per session/week)
- Novices don't need deloads — "they didn't work hard enough to merit one" [T15, T16]
- 5/3/1 progression: +5–10 lb per 4-week cycle [T16]

## Autoregulation & Feedback Loops

**The logbook feedback loop [T18]:**
- If next session's numbers aren't moving up → the previous session's volume was too high → reduce it and rerun
- If numbers move → you found your volume sweet spot. Iterate session by session.
- "If performance goes up → volume is right; if not → scale volume back" [T8]

**Deload timing cues [T15]:** feeling beat up, losing motivation, staying sore longer, light weights feeling heavy, **can't get a pump**. Deload every ~8–12 weeks or by symptoms.

## The Split-Agnostic Engine (design principle)

**Within hypertrophy training, the progression engine is universal — the split is just the container.** When building any program, treat these as independent layers:

**Layer 1 — The engine (same for every hypertrophy split):**
1. Volume/frequency targets (10–20 sets/muscle/wk, 2×/wk frequency) — the "what"
2. Weekly progression method (A: add reps / B: add sets / C: RPE ramp) — the "how much over time"
3. Block structure (4 overload weeks → deload → small change between blocks)
4. Logbook feedback loop (numbers drop → cut prior session's volume and rerun)

This is why "any split is justified — pick what you'll actually follow" [T2]: they all run the same engine.

**Where the engine genuinely differs:**
- **Strength-focused programs** (conjugate, 5/3/1, Texas Method, HLM) use load-percentage waves, weekly lift rotation, and volume cycling instead of rep accumulation [T9–T14, T16]. Different goal = different engine.
- **Exercise swap trigger:** hypertrophy blocks dropping below ~6 reps = swap signal; strength programs treat heavy-low-rep as normal [T6].
- **Deload lever matches the stressor:** volume-driven split → cut volume ~50% (keep load); intensity-driven program → cut load to ~60% (keep volume) [T15]. Same timing, different lever.

**Split-dependent adjustment — "gear ratio":** frequency shapes progression granularity, not the engine. A muscle trained 3×/wk gets 3 weekly progression slots (smaller increments each); 1×/wk (bro split) gets 1 slot (bigger per-session jumps). Same engine, different gearing [T18, 18].

**Practical rule for program design:** choose the split by schedule/preference/fatigue constraints, then bolt on the standard engine unchanged. Only deviate when the goal is strength, not hypertrophy.

## What NOT to Do

- Don't jump into an advanced template without work-capacity progression (T7 author couldn't recover from PHAT at 19–20) [T7]
- Don't chase "the optimal thing" year-round [T2]
- Don't judge volume by feelings — judge by progress [T16]
- Don't let soreness or pump stand in for logbook progress [T18, T19]
