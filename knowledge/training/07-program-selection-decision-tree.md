# Program Selection Decision Tree

*Synthesized from transcripts 6, 7, 9, 13, 14, 16, 17, 18, 19, 20, 21, 22 — this file is the "how to match a program to a person" playbook.*

## Step 0: Assess the Current State FIRST

Before choosing anything new [T17, T18]:
0. **No structured current program?** → skip the audit; start volumes at
   mid-band (conservative: middle of the 10–20 growth band for priorities,
   below it for everything else) and let the logbook calibrate from week 1.
1. Audit **current volume per muscle per week** from the existing program. A new split that REDUCES your volume is an atrophy program.
2. Audit the **logbook**: which muscles/lifts have progressed in the last months? Which stalled? (Visuals + load/reps)
3. Audit **session quality**: do back-half exercises still progress? Do sessions blow past 1.5 h?

## Decision Tree: Choosing a Split

**Precedence rules:** evaluate top to bottom — the first YES wins. However,
"Progressing on all lifts? → change NOTHING" [T16] overrides every
structure-change branch; while progressing, only the fatigue/schedule
branches (sessions too long, schedule can't do fixed days) may fire.

```
START
│
├─ Training age < ~1 year (or new to structured training)?
│   └─ YES → Full Body 3×/week
│        (novices: "a little stimulus does a lot"; 1–3 hard sets/exercise;
│         no deloads needed; blunt heavy compounds are fine; groove technique
│         with repeated sets — not one all-out set)
│
├─ Sessions too long (>1–1.5h) OR back-half lifts stalling from cumulative fatigue?
│   └─ YES → move UP the ladder: Full Body → Upper/Lower → PPL
│
├─ Fresh at end of every session + fully recovered between sessions?
│   └─ YES → you can REGRESS (e.g., PPL → U/L or hybrid) and concentrate
│        stimulus quality — regression can be progress [T17]
│
├─ Only ~45 min/session available?
│   └─ YES → body-part split days (or max 2 muscle groups per day)
│
├─ Schedule can't do fixed weekdays?
│   └─ → rotating PPL (3 on 1 off) — trade consistency for rest days
│   └─ Fixed weekday schedule needed? → hybrid PPL with fixed rest days,
│        or synchronous 4-day U/L (Mon/Tue/Thu/Fri)
│
├─ Arms are the priority?
│   └─ → Torso/Limb split run 6 days/wk (arms 4×/wk, no dedicated arm day) [T8]
│
├─ One muscle/group badly lagging?
│   └─ → Specialization: cut a strong area to maintenance (~bare-bones day),
│        reallocate its volume; lagging part 2–3×/week [T17, T18]
│        (guardrail: one priority ideally, two at most, and the cut volume
│        must fund the added sets — volume is reallocated, not conjured)
│
├─ No condition fired (healthy intermediate, no complaints, normal
│   schedule and recovery)? → YES → Upper/Lower — the intermediate
│        default [T22: "the sweet spot for intermediates"], scaled to the
│        days actually available; the specialization branch may reshape
│        this container (e.g. 3 uppers + 1 lower for an upper priority)
│
└─ Advanced (10+ years, everything plateaued)?
    └─ → "Inside-out" programming: start from per-muscle volume needs,
         proximity-to-failure habits, preferred exercises, schedule/recovery
         constraints — let the split EMERGE (don't start from a template) [T7]
```

## Decision Tree: Match Program Difficulty to the Person (strength context)

```
Age / lifestyle / recovery budget?
│
├─ 20s, training is life priority #1–2, unlimited time
│   └─ → aggressive: Texas Method, all-heavy 4-day, TM-style volume+intensity
│
├─ 35–40 gray zone → depends on sleep/food/stress/time (trial HLM first)
│
├─ 40+ or big life/job/family load or concurrent sport (MMA, BJJ, running)
│   └─ → HLM (Heavy-Light-Medium): only one maximal day per lift/week;
│        "athletes are like older people" re: recovery drain [T13]
│
└─ Failure signatures:
    ├─ REGRESSING (did 405×5, now fail 410) = overtrained (TM-style problem)
    │   └─ → deload, cut intensity frequency
    └─ STALLING (stuck but not regressing) = undertrained (HLM problem)
        └─ → shrink light/medium offsets (20%→10%, 10%→5%), add a set
```

## Decision Tree: Volume Prescription

```
Per muscle, per week:
├─ Goal: retention only          → ~3 hard sets/week [T22]
├─ Goal: steady growth, minimal  → 6–8 sets/week [T22]
├─ Default growth prescription   → 10–20 sets/week [T1, T6]
├─ High-volume responder (trial) → up to 20–30 sets/week [T6]
└─ Hard cap signals: >10–12 sets/week yields minuscule ROI for most;
   within a session, ~6 hard sets/muscle is the plateau [T22];
   per exercise per session: ≤5 sets, then switch angle [T6]

Calibrate by feedback loop [T18]:
└─ If next session's numbers drop → previous session volume too high → cut & rerun
   If numbers rise → keep. Iterate session by session.
```

## Decision Tree: Effort Prescription

```
├─ Exercise type:
│   ├─ Heavy free-weight compound (squat/bench/dead/RDL) → stop 1–3 RIR even on last set
│   ├─ Machine/cable (low systemic fatigue) → last set to failure, earlier sets 1–2 RIR
│   └─ Isolation → can go to failure regularly
├─ Experience: novice → RIR is loose (they can't push hard anyway);
│   intermediate+ → explicit RIR/RPE targets [T3, T6]
└─ Individual preference: if someone demonstrably grows on all-out training
   (T21-type), that's valid — the logbook decides
```

## Decision Tree: When to Change Something

```
├─ Progressing on all lifts? → change NOTHING. "If you're progressing,
│   it's the right amount of work" [T16]
├─ Weak point identified after ~3 years / ~30 lb muscle gained? [T21]
│   └─ → specialization block (volume shift + frequency bump to 2–3×/wk)
├─ Stalled a full block (4–6 weeks)? → see 04-progression (block swap,
│   load/rep cycle, exercise swap)
├─ Feeling beat up (see 06 warning signs)? → deload matching the stressor
└─ Bored / dreading sessions? → swap split style — consistency beats optimality
```

## The Meta-Rules (highest priority, all sources agree)

1. **Volume-per-muscle needs dictate the split — never pick a split first and force volume into it** [T7, T17]
2. **Consistency > optimization.** The best program is the one you'll run [T19, T20, T21, T22]
3. **The logbook is the judge.** Progress = the only valid feedback [T16, T18, T19]
4. **Templates fit ~95% of people** — inside-out design is for advanced athletes [T7]
5. **Specialize only after the foundation** — "I have weak arms" at 3 months means you have weak everything [T21]
