# Back Training: Lats, Traps, Rear Delts, Erectors

*Source: Program Design/back/1–8 (Nippard anatomy guides, J3U, Rambod/Vissers prep, IFBB pro "pull day" system, Meadows 21 tips)*

## Anatomy & Function Map

- **Lats (width):** two functions — shoulder **adduction** (arm in from the side; wide-grip bias) and shoulder **extension** (arm in from the front; narrow/close-grip bias). Train both. Lats are extremely hard to fully SHORTEN — huge strength discrepancy between lengthened and shortened positions [back/1, back/3, back/6].
- **Traps (thickness):** upper traps = scapular **elevation** (shrugs); mid/lower traps = scapular **retraction** (rows). Trap fiber orientation means shrugs need a slightly wider grip [back/1]. Dumbbell shrugs only hit upper fibers — mid/lower need direct retraction work (Kelso shrugs) [back/4].
- **Rhomboids:** retraction — trained with mid-trap exercises [back/1, back/4].
- **Spinal erectors:** extension of spine; deadlifts/squats recruit them heavily — isolation rarely needed; weighted back extensions if avoiding compounds [back/1, back/8].
- Fiber types: lats/traps predominantly fast-twitch (respond to heavier loads); erectors type-I dominant (tolerate lighter loads) — still use varied rep ranges [back/1].
- **"Vertical = width, horizontal = thickness" is an oversimplification.** Rows produce same-or-greater lat activation than pulldowns (seated cable row > bent-over row; chest-supported > free-standing because no low-back stabilization cost) [back/1, back/3].

## Exercise Selection by Region

### Lats
- **Pulldown grip:** front-of-neck (never behind-neck), **medium ~1.5× shoulder width**, pronated (pronated beats supinated; medium beat narrow and wide in relative-load studies). V-bar/neutral grip = trains lats via extension in a vertical pull — valid personal preference [back/1, back/3].
- Pull-ups ≈ pulldowns for lats; pull-ups add more biceps work → pulldown is the better lat-isolation pick [back/1].
- **Rows for lats:** close/V-bar grip, cue "drive elbows down and in" [back/3]. Chest-supported t-bar row = staple [back/1].
- **Horizontal single-arm machine row** with hips shifted back + chest glued to pad = locked-in lat bias ("driving down more than retracting") [back/6].
- **Rack pull at mid-shin height** (not floor deadlifts) for lat emphasis — flex lats, pull elbows back ≈ shoulder extension [back/8]. Floor pulling (stiff-legs from floor) builds visually dense "thickness" — the pro's #1 back builder, no eccentric control needed when legs follow 2 days later [back/6].
- Dumbbell pullover: fixed slight elbow bend, pull with lats; ascend only to forehead height — past that, tension is lost [back/8].
- Lat pre-activation (pull-ins, pullovers, palpation cues) raises pulldown lat EMG [back/1].

### Mid/Upper Traps & Rhomboids
- Wide-grip seated cable row, 12–15 reps, hold the squeeze 1–2 s at top; lighter loads prevent lats taking over [back/2].
- **Kelso shrug** (at end of a row: retract/protract the scapulae with arms ~90°–45° from torso) = the direct mid/lower trap solution. Start **3 sets/session × 2 sessions/wk = 6 sets/wk**; assess at 8 weeks; progress to 6×2 (12 sets/wk) if recovering well. Priority placement: row→Kelso as first lift of the day [back/4].
- Barbell shrugs: slightly wider grip (upper-trap fiber orientation); heavy power-shrug style allows closer grip [back/1].

### Rear Delts (also see 12-shoulders)
- Pec-deck rear delt fly seated sideways: "sweep the floor" huge ROM; traditional setup cuts off the stretch half [back/2].

### Erectors
- Deadlift/squat coverage usually sufficient; weighted back extensions as the isolation option; hyperextension pad height matters — rise only to neutral spine [back/1, back/8].

## Session Sequencing (resistance profiles)

Lats retain strength in the lengthened position; shortened-position strength degrades fastest with fatigue [back/6, chest/3 principle]:
1. Shorten-biased machine work EARLY (when you can still shorten)
2. Drop-off-short machines later
3. Horizontal lengthening work LAST
A machine that doesn't drop off in the short position is "a waste of time" once fatigued [back/6].

## Programming Numbers

- Frequency: **2–3×/week** [back/1]; back recovers well (upper back tolerates high frequency) [back/7]
- Volume caution: **>25 working sets/week = recovery problems for most** [back/1]
- Weak-point hack: 3–4 quick wide-grip pull-up sets at the end of non-back days for extra weekly volume [back/1]
- Cutting phase: **low volume, high intensity** — 1–2 brutal sets/exercise; maintenance possible on 1/9th of volume [back/2]
- Pro back day structure [back/6]: floor pull (1–2 sets) → lat shorten-biased work (3–4 sets) → upper back (2 sets) → horizontal lat finisher (~5 sets total lat) → rear delts/traps
- Low-rep (3–4 rep) lat work is NOT needed for hypertrophy — only for strength goals [back/6]
- Extra sets only when robust; a non-PR session is almost a deload — "volume doesn't equate to fatigue" [back/6]

## Technique Master List (the mistakes that stall backs)

- **Biceps take-over = #1 mistake** [back/1, back/8]: elbow-driven cues, pre-activation, chest-supported setups, straps on heavy sets (grip never as strong as lats — not strapping limits back training; don't use on every set) [back/8]
- **Sternum up / no chest cave** on pulldowns [back/5, back/8]; flat (not hyper-arched) spine on rows; bar kept tight to body; knees soft [back/8]
- No jerking/launching from the stretch; start every row from full stretch [back/8]
- DB rows: no torso twist, stable both-feet stance (not knee-on-bench), grab dumbbell in the middle, rest ~2 min between sides on heavy all-out sets [back/8]
- Active (not passive) stretch — stay engaged at the bottom of pulldowns; hips down for lower-lat stretch [back/5]
- Lats harder to shorten than upper back: even-resistance cables fine for upper back, profile-matched machines needed for lats [back/6]
- Chest pad rule: lat work = hips back; upper back = hips under, chest up [back/6]
- Belts on heavy barbell rows only (delay adoption to build erector strength) [back/8]

## Contradictions Logged

- Rambod-style prep coaching (forced reps, partials, assisted negatives, 0-RIR grinding) vs. baseline 2–3 RIR — elite late-prep context [back/5]
- Nippard rejects blanket RIR prescriptions (people undertrain when told "2 RIR"); prescribes set 1 @ 1–2 RIR, set 2 to failure [back/2]
- "Stretch training overhyped in trained lifters" (Nippard's own study: full ROM = lengthened partials in trained subjects) vs. stretch-first emphasis elsewhere — tempered, not reversed [back/2]
