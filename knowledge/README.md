# Knowledge Library

Everything needed to write accurate, current scripts.

## What lives where

- `transcripts/` — YouTube transcripts, one folder per video
  (`Channel - Video Title/transcript.txt`)
- `reddit/` — pasted threads, one file per thread
- `news/` — industry news (see `news/SOURCES.md`)
- `research/` — evidence summaries I maintain (stable science + key numbers)

## Division of labor

- I CAN fetch directly: Stronger By Science, BarBend, most article/news sites
- I CANNOT fetch: Reddit (blocked), YouTube transcripts (JS player),
  Instagram

For blocked sources: paste content into the right folder.

## Conventions

Every pasted file gets this header:

```
source: <URL>
fetched: <date>
why: <which series/episode this feeds>
```

After reading a new source I add key takeaways + script angles to a
NOTES section in the same file, so the library stays searchable.
