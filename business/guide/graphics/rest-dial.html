Rest Between Sets

You're resting for performance per set — and therefore stimulus per set

THE BASELINE
2–3 min

Standard hypertrophy rest

3 minutes beats 1 minute. If you're used to 60-second bro-rest, this feels long — do it anyway.

HEAVY LEG WORK
4–5 min

When the bar is big

Squats, deadlifts, heavy pressing — the systemic bill is larger, and the next set pays for shortchanging it.

TIME-SAVER
A↔B superset

Antagonist pairing

Biceps with triceps, quads with hams — one muscle recovers while the other works. Performance-free shortcut.

Rest capacity is trainable: gradually shortening rest over weeks costs surprisingly little growth.
