# Level Differentiation Matrix

Training-age level is a **profile that differentiates the whole program
structure**, not a parameter tweak on one stage. Apply this matrix after the
intake, before any stage of the design pipeline. Citations as in
`knowledge/08-source-map.md` (`[T#]` = `raw/transcript#.txt`).

Levels (hypertrophy ladder, per `knowledge/training/07`):

- **Beginner** — training age < ~1 year (or new to structured training)
- **Intermediate** — progressing on structured training, no special complaints
- **Advanced** — 10+ years, near genetic ceiling, everything plateaued [T7]

> Do **not** conflate with the strength-sport difficulty tree in `knowledge/training/07`
> (Texas Method / HLM, driven by age/lifestyle/recovery). That tree is a
> secondary *moderator*: an advanced lifter with a big life load or 40+ still
> gets moderate-difficulty design (HLM logic). Also note templates fit ~95% of
> people — "advanced" is still a template, just a richer one; inside-out
> free-form design is for true edge cases [T7].

## The matrix

| Variable | Beginner | Intermediate | Advanced |
|---|---|---|---|
| Container | Full body 3×/wk [T7-tree] | Upper/Lower — "the sweet spot for intermediates" [T22]; scaled to days available | Any container; specialization may reshape it; "inside-out" only for true plateau [T7] |
| Block structure | Longer linear blocks, **no deloads** — "they didn't work hard enough to merit one" [T15, T16] | 4 overload + 1 deload (typical) [T6] | ~3 overload + 1 deload; symptom-driven timing (every 4–12 wk) [T6, T15] |
| Progression method | Linear / double progression; fast jumps (+1–3 reps/wk) [T13, T16] | Method A (+1–2 reps/wk), B (+1 set/wk), or C (RPE ramp) — pick one per block [T6] | +0–1 reps/wk; alternate high-volume and logbook-focused blocks [T2]; block-to-block load/rep cycling [T6] |
| Starting volume | Low — "a little stimulus does a lot"; 1–3 hard sets/exercise [T7-tree] | Mid-band 10–20 sets/muscle/wk for priorities, below for the rest [T1, T6] | Calibrated per muscle from logbook; high-responder trial up to 20–30 sets [T6]; volume is a phase dial [T2] |
| Exercise selection | "Blunt and basic" — master the basics; variation is a tool, not a necessity [T2]; repeated sets to groove technique, not one all-out set [T16] | Standard variety: 2–4 exercises/muscle across angles, stretch bias [T5, T6] | Lengthened-position bias front and center [T3, T4]; exercise swaps after 2–5 load-increase blocks or <6 reps [T6]; conjugate-style rotation optional [T9–T11] |
| Alternatives list | Short and boring (equipment/injury swaps only) [T2] | Standard per-slot curated lists [T5] | Richer: micro-variations count (foot placement etc.) [T5, T17] |
| Effort (RIR) | Loose — novices can't push hard enough to need precise targets [T3, T6] | Explicit RIR/RPE targets by exercise type [T6, T07-effort-tree] | Explicit; failure experimentation valid if the logbook confirms growth (T21-type) [T21] |
| Frequency | Whatever the split gives | Each muscle ≥2×/wk [T1, T5, T18] | Slight edge 2–3×/wk [T18]; high-frequency low-volume option for recovery-limited advanced [T22] |
| Supersets | Avoid — straight sets to groove technique | Antagonist pairs (bi/tri, quad/ham) for time at session end [T4, T23] | Fine; plus intensity techniques (myo-reps, partials) as separate per-exercise flags, not scheduling supersets [shoulders/3, shoulders/6] |
| Specialization | Never — "weak arms at 3 months means you have weak everything" [T21] | After foundation; weak-point work once identified [T21] | Legitimate: cut a strong area to maintenance, reallocate; 1 priority (2 max) [T17, T18] |
| Deload lever | n/a (no deloads) | Volume halved, load kept (~5–10% drop) — volume is the stressor [T15] | Match lever to stressor; frequency deload (spread week over 8–12 days) is a standing option [T15] |
| Autoregulation | Logbook loop (numbers drop → cut prior session volume, rerun) [T18] | Same | Same + symptom checklist gates deloads [T15, T20] |

## Interaction with split-duration selection (app ordering)

When a container is chosen before the block length (level → duration → split
type), validate the combination against this matrix:

- Beginner + any split longer than ~8–12 weeks without progression re-eval →
  wrong; novice linear progression lasts 3–6 months total, then the lifter
  graduates [T13, T16].
- Advanced + long blocks (>6 overload weeks) → wrong; advanced ≈ 3 overload
  weeks before fatigue wins [T6].
- Deload week present in a beginner program → remove [T15, T16].
- Specialization volume in a beginner/early-intermediate program → remove
  and redistribute to base volume [T21].

## Moderators that override level

From `knowledge/training/07` difficulty tree and `knowledge/training/06`:

- **Recovery budget** (sleep/stress, intake Q13) poor, or 40+ / big life
  load / concurrent sport → moderate the design regardless of level
  (HLM-style: one maximal day per lift/week) [T13].
- **Caloric deficit** (intake Q14) → distribute leg volume as single
  movements, keep 1 heavy top set [T7].
- **"Progressing on all lifts? Change NOTHING"** [T16] — overrides every
  structure-change branch at any level.
